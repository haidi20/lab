**Tanggal:** 3 November 2026
**Mesin:** Windows (VS Code, 5 window aktif)
**Lingkup masalah:** OpenAI Codex extension (`openai.chatgpt`) + Codex CLI + jaringan

## Masalah 1: "Codex could not start" (UI gagal startup)

### Gejala

- Extension terinstall (`openai.chatgpt-26.1021.22027-win32-x64`) tapi saat dibuka muncul error: *"Codex could not start. The extension could not start its user interface."*
- **Tidak ada `Codex.log` di sesi log mana pun** (`%APPDATA%\Code\logs\<sesi>\...\exthost\OpenAI.ChatGPT\`) — ekstensi crash di fase startup webview, **sebelum sempat menulis log**. Ini yang membuat diagnosis awal terasa jalan buntu.

### Akar Penyebab

Bug di webview ekstensi versi **26.1021.22027**: renderer UI gagal ready dalam batas waktu 30 detik (`renderer_ready_timeout`). Bukan masalah sistem lokal — menimpa banyak pengguna lintas OS.

Referensi:
- https://github.com/openai/codex/issues/56655
- https://github.com/openai/codex/issues/57032
- https://smartscope.blog/en/blog/openai-codex-codex-not-start-vs-code-error-2026/

### Solusi: Downgrade + Pin

```powershell
# 1. Uninstall versi rusak
code --uninstall-extension openai.chatgpt

# 2. Install versi stabil terakhir
code --install-extension openai.chatgpt@26.1007.21434 --force
```

Alternatif via UI VS Code: Extensions sidebar → gear icon pada extension Codex → **Install Specific Version...** → pilih `26.1007.21434`.

### Catatan Khusus: Install Gagal via Marketplace (jaringan IPv6 rusak)

Di mesin ini `code --install-extension openai.chatgpt@26.1007.21434` **menggantung tanpa error** — download marketplace tersangkut di jalur IPv6 yang rusak (lihat Masalah 2). Workaround yang berhasil:

```powershell
# Download VSIX langsung, dipaksa IPv4 (untuk Windows x64 WAJIB targetPlatform)
curl.exe --ipv4 -sL -o "$env:TEMP\codex-win.vsix" `
  'https://marketplace.visualstudio.com/_apis/public/gallery/publishers/OpenAI/vsextensions/chatgpt/26.1007.21434/vspackage?targetPlatform=win32-x64'

# Marketplace mengirim gzip mentah - cek magic byte lalu dekompres jika perlu
# magic '1F 8B' = gzip -> dekompres; magic 'PK' = zip/VSIX -> langsung pakai
Add-Type -AssemblyName System.IO.Compression
$in  = [System.IO.File]::OpenRead("$env:TEMP\codex-win.vsix")
$gz  = New-Object System.IO.Compression.GZipStream($in, [System.IO.Compression.CompressionMode]::Decompress)
$out = [System.IO.File]::Create("$env:TEMP\codex-win-dec.vsix")
$gz.CopyTo($out); $out.Close(); $gz.Close(); $in.Close()

# Install dari file lokal (tanpa jaringan)
code --install-extension "$env:TEMP\codex-win-dec.vsix" --force
```

**Jebakan yang ditemukan:** tanpa `?targetPlatform=win32-x64`, marketplace mengirim build **universal** yang hanya berisi `bin/linux-aarch64` — extension terinstall tapi **tidak punya `codex.exe` Windows** dan pasti gagal jalan. Selalu sertakan `targetPlatform`.

### Pembersihan Sisa Versi Lama

Proses `codex.exe` lama bisa mengunci folder versi lama — kill dulu sebelum hapus:

```powershell
# Cari proses yang mengunci (perhatikan path di CommandLine)
Get-CimInstance Win32_Process | Where-Object { $_.Name -match 'codex' } |
  Select-Object ProcessId, CommandLine

# Kill, lalu hapus folder lama
taskkill /F /PID <pid>
Remove-Item "$env:USERPROFILE\.vscode\extensions\openai.chatgpt-26.1021.22027-win32-x64" -Recurse -Force
Remove-Item "$env:USERPROFILE\.vscode\extensions\openai.chatgpt-26.51021.22027-win32-x64" -Recurse -Force
```

Bersihkan juga `%USERPROFILE%\.vscode\extensions\.obsolete` jika masih berisi entri folder lama (cukup isi `{}`), dan verifikasi `extensions.json` konsisten.

## Masalah 2: `stream disconnected before completion` (IPv6)

### Gejala

- Codex chat tiba-tiba terputus dengan error `stream disconnected before completion`.
- Pola khas: response selalu terpotong di **~10 KB (10.276 bytes)** saat `auth_mode = chatgpt` (koneksi langsung ke chatgpt.com).

### Akar Penyebab

**Konektivitas IPv6 rusak** di mesin atau router:

```
curl -6 https://chatgpt.com   -> HTTP 000, 0 bytes (GAGAL)
curl -4 https://chatgpt.com   -> normal
```

Karena chatgpt.com mendukung IPv6, OS memilih jalur IPv6 yang mati itu -> stream terputus di tengah jalan.

**9Router sendiri sehat**: stream test 712 KB berakhir `[DONE]`, `/v1/models` valid (23.703 bytes), PID 15956, port 20128, v0.5.112. Jalur 9Router = **localhost** -> tidak terdampak IPv6.

### Solusi (belum diterapkan)

Perbaiki IPv6 di **router** (preferred) atau **adapter jaringan** Windows:

- Router: cek setting DHCPv6/Prefix Delegation dari ISP; atau disable IPv6 di router jika ISP tidak mendukung penuh.
- Windows adapter (perlu admin):
  ```powershell
  Disable-NetAdapterBinding -Name "Ethernet" -ComponentID ms_tcpip6
  ```
  atau via GUI: `Network Connections` -> adapter aktif -> Properties -> uncheck **Internet Protocol Version 6 (TCP/IPv6)**.
- Setelah diperbaiki, verifikasi: `curl -6 https://chatgpt.com` harus merespons.

**Catatan:** masalah ini menimpa **semua aplikasi** yang mengakses host dual-stack, bukan hanya Codex.

### Mitigasi Sementara

Gunakan Codex lewat **9Router** (`model_provider` -> `http://localhost:20128/v1`, key `sk_9router`) — localhost tidak lewat IPv6, jadi stream stabil.

## Langkah yang Harus Dilakukan User

1. **Reload semua window VS Code**: `Ctrl+Shift+P` -> *Developer: Reload Window*.
2. Jika error UI masih muncul (kemungkinan kecil): tutup semua window VS Code, hapus cache webview, buka lagi:
   ```powershell
   Remove-Item "$env:APPDATA\Code\Service Worker\CacheStorage" -Recurse -Force
   Remove-Item "$env:APPDATA\Code\Service Worker\ScriptCache" -Recurse -Force
   Remove-Item "$env:APPDATA\Code\Code Cache" -Recurse -Force
   Remove-Item "$env:APPDATA\Code\Cache" -Recurse -Force
   Remove-Item "$env:APPDATA\Code\CachedData" -Recurse -Force
   Remove-Item "$env:APPDATA\Code\GPUCache" -Recurse -Force
   ```
3. Re-konfigurasi `~/.codex/config.toml` (profil 9Router: `model_provider` -> `http://localhost:20128/v1`, key `sk_9router`) jika ingin langsung pakai jalur 9Router.
4. **Perbaiki IPv6** (lihat Masalah 2) — sampai itu dilakukan, hindari `auth_mode = chatgpt`.

## Pelajaran Penting

1. **Tidak ada `Codex.log` = ekstensi mati sebelum logging dimulai** — jangan buang waktu mencari log; langsung cek versi ekstensi dan issue tracker.
2. **`26.1021.22027` adalah versi bermasalah** — downgrade ke `26.1007.21434` adalah fix resmi dari komunitas sambil menunggu patch OpenAI.
3. **Marketplace VSIX selalu gzip mentah** via endpoint `/vspackage` — cek magic byte (`PK` vs `1F 8B`) sebelum install.
4. **Selalu sertakan `?targetPlatform=win32-x64`** saat download VSIX untuk Windows — build universal tidak berisi binary Windows.
5. **IPv6 rusak = dua efek sekaligus**: stream Codex terputus DAN instalasi ekstensi menggantung. Fix jaringan menyembuhkan keduanya.
