# Emil Kowalski Animation Skills

Paket skill ini disalin dari
[emilkowalski/skills](https://github.com/emilkowalski/skills) sebagai
referensi lokal untuk animasi proyek ini.

Folder yang dipakai:

- `animate/`
- `animation-vocabulary/`
- `animation-performance/`
- `review-animations/`
- `improve-animations/`
- `find-animation-opportunities/`
- `emil-design-eng/`

Jangan mengubah isi skill tanpa memperbarui dari upstream. Implementasi
proyek harus mengikuti standar motion, timing, stagger, dan review yang
ada di folder tersebut.
